빈칸을 누르면 시간을 막거나 수강생 대신 예약할 수 있고, 예약을 누르면 취소할 수 있어요.

카카오 연결 요청

학생이 처음 카카오로 로그인하면 여기에 요청이 와요. 맞는 수강 ID를 골라 승인하면, 그 학생은 다음부터 카카오 버튼 한 번으로 들어와요.

    새 수강 ID

    학생이 "내 폴더"에서 보는 내용이에요.

    레슨 노트

      월말평가 올리기

      평가지는 PDF나 사진 모두 돼요. 파일 이름을 학생이름.pdf 또는 학생이름1.jpg, 학생이름2.jpg처럼 두면 알아서 학생을 찾아요. 여러 학생이 든 PDF 하나도 괜찮아요 (쪽마다 적힌 "학생명"으로 나눠요). 점수는 "통합 결과" 시트에서 표를 복사해 붙여넣으면 같이 들어가요.

      이 달에 올린 평가

        인스타그램 연결

        확인 중…

        토큰은 비밀번호 같은 거라 채팅이나 카톡에 올리지 말고 여기에만 붙여넣어 주세요. 저장하면 다시 보여주지 않아요.

        가져온 인스타 글 (칸 옮기기 · 숨기기)

        글 내용으로 칸을 저절로 골라요. 틀린 칸은 여기서 바꾸면 다음부터 그대로 둬요. 숨긴 글은 홈페이지에 안 보여요.

          새 소식 올리기

          올리면 홈페이지 "오디션 소식"에 바로 보여요. 학원 내방 오디션을 올리면 학생 신청서가 같이 열려요 (내용에 일시·장소·지원자격·지원분야를 적어주세요, 접수 마감이 지나면 닫혀요). 합격 소식에는 학생 실명 대신 이니셜(예: 김OO)로 써주세요. 합격 소식은 about의 합격 실적판(연도별 기획사, 기획사 카드, 숫자)에도 저절로 더해져요.

          올린 소식

            새 공지 쓰기

            수강생만 봐요 (내 폴더 → 일정·공지). 휴원일, 월말평가 날, 행사처럼 학생이 알아야 할 것을 적어주세요. 날짜를 넣으면 "다가오는 일정"에 날짜순으로, 안 넣으면 "공지"에 보여요. 제목에 "월말평가"·"휴원"이 들어가면 그 표시가 붙어요. 학원 내방 오디션은 "오디션 소식"에 올리면 여기에도 저절로 보여요. 끝나는 날이 지나면 저절로 안 보여요.

            올린 공지

              학생이 홈페이지 신청서(오디션 소식 → 내방 오디션 신청하기)로 낸 신청이에요. 신청서는 오디션 소식 탭에서 "학원 내방 오디션"을 올리면 생겨요 (내용에 일시·장소·지원자격·지원분야를 적으면 신청서 위에 그대로 보여요). 마감일이 지나면 신청이 닫혀요. "표로 복사"를 누르면 구글시트에 그대로 붙여넣을 수 있어요.

              추천 신청

              학생이 내 폴더에서 신청하면 여기에 보여요. 학생이 녹음해서 올린 노래는 여기서 듣고 내려받아요 (카카오톡 채널로 받은 영상도 그대로 써도 돼요). 추천을 올린 뒤에는 녹음 지우기를 눌러주세요.

                노래 추천 올리기

                Claude와 만든 목소리 분석·추천곡 시트에서 ① 분석 요약부터 ③ 추천곡까지 드래그해서 복사 → 붙여넣기 하면 알아서 나눠요. 학생에게는 음역·음색·분위기·추천곡(이유, 멜론·Spotify 링크)만 보이고, 센트·dB 같은 숫자와 "참고" 칸은 안 보여요. Claude에게 "○○ 노래 추천 올려줘"라고 말해도 돼요.

                올린 추천

                  학생이 직접 쓴 연습 일지와 레퍼토리예요. 수업 전에 참고하세요 (고치거나 지우는 건 학생만 해요).

                  학생이 내 폴더 → 제휴 업체에서 낸 신청이에요. 업체에 전화로 예약한 뒤 예약 완료로 바꾸고 "학생에게 보낼 말"에 날짜·시간·준비물을 적어 저장하면 학생 내 폴더에 그대로 보여요.

                    제휴 업체 목록 고치기 (이름·안내 적기)

                    학생 신청 화면에 보이는 업체예요. 업체 이름과 안내(위치·혜택·준비물 등)를 적으면 학생이 고를 때 보여요. 숨기면 학생 화면에서 빠져요 (예전 신청은 그대로).

                        카카오톡에 넣을 주소

                        카카오톡 채널 메뉴나 단톡방 공지에 넣으세요. 누르면 그 화면이 바로 열려요. 한 번 로그인한 학생은 다시 로그인하지 않아도 돼요.
