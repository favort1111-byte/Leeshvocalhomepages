# 이송희보컬레슨 홈페이지

강남 선릉역 1:1 보컬학원 이송희보컬레슨 공식 홈페이지 (정적 HTML/CSS/JS, 빌드 도구 없음).

## 실행 방법

별도 설치 없이 `index.html`을 브라우저로 열거나, 로컬 서버로 확인하세요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 구조

```
index.html      메인 페이지 (전 구간 단일 페이지)
css/style.css   전체 스타일 (딥그린 #1D4948 + 골드 #E3B341)
js/main.js      모바일 메뉴, 상담 폼 처리
```

## 다음에 채워야 할 것 (플레이스홀더)

- **원장님 실제 프로필 사진** — `.director__photo`에 텍스트 플레이스홀더 대신 실제 사진 필요
- **시설 갤러리 실사진** — `#facility` 카드에 연습실/레슨실 실사진 필요
- **유튜브 영상 임베드** — 현재는 채널 링크 + 텍스트 리스트만 있음. 실제 영상 ID를 알려주시면 임베드로 교체 가능
- **수강생 후기** — 확보되면 별도 섹션 추가 권장
- **상담 폼 자동 전송** — 현재는 입력 내용을 클립보드에 복사 후 카카오톡 채널로 이동하는 방식(백엔드 없음). 실제 자동 접수가 필요하면 폼 수신 서비스(예: Google Form 연동, 자체 서버) 연결 필요
- **도메인/배포** — leeshlesson.com 유지 여부 및 배포처(GitHub Pages, Netlify 등) 결정 필요
