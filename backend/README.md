# 홈페이지 시스템 설치 안내 (구글시트 + 앱스스크립트)

홈페이지의 **상담 신청 · 방문/체험 상담 예약 · 수강생 연습실 예약 · 문구 수정**을 처리하는 서버입니다.
기존 학생관리·레슨실 예약 시스템과는 **완전히 별개**인 새 구글시트 하나로 돌아갑니다.

처음 한 번만 아래 순서대로 하시면 됩니다. 30분 정도 걸려요.

---

## 1. 새 구글시트 만들기

1. https://sheets.new 에서 새 시트를 만들고 이름을 `이송희보컬레슨 홈페이지`로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.

## 2. 코드 넣기

Apps Script 편집기에서:

1. 왼쪽 **파일** 옆 `+` → **스크립트**로 파일 5개를 만들고, 이 폴더의 같은 이름 파일 내용을 그대로 붙여넣습니다.
   `Api`, `Logic`, `Notify`, `Setup`, `Sheets` (처음 있던 `Code.gs`는 지워도 됩니다)
2. 왼쪽 **프로젝트 설정(톱니바퀴)** → **"appsscript.json" 매니페스트 파일 표시** 체크
   → 편집기로 돌아와 `appsscript.json`을 이 폴더의 파일 내용으로 바꿉니다.
3. 저장(💾)합니다.

## 3. 시트 탭 만들기

1. 구글시트로 돌아가 새로고침하면 메뉴에 **홈페이지**가 생깁니다.
2. **홈페이지 → 초기 설정 (탭 만들기)**를 누릅니다. 처음에는 권한 승인 창이 뜹니다.
   "확인되지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)으로 이동**을 누르면 됩니다. 원장님이 만든 스크립트라서 뜨는 경고예요.
3. 탭 11개가 생깁니다. 아래 표를 보고 **수강생**과 **연습실** 탭부터 채워주세요.

| 탭 | 하는 일 | 원장님이 할 일 |
|---|---|---|
| 설정 | 예약 규칙 (1회 최대 시간, 하루 최대, 며칠 앞까지 등) | 필요하면 값만 바꾸기 |
| 콘텐츠 | 홈페이지 문구 (키마다 한 줄) | 문구 수정 — 저장하면 바로 반영 |
| 합격실적 · 수강료 | 목록형 콘텐츠 | 행 추가·수정, 숨기려면 표시=N |
| 연습실 | 예약받을 방 목록 | **실제 방 이름으로 바꾸기** |
| 수강생 | 연습실 예약 본인 확인용 명단 | **이름·전화번호·상태(재원) 입력** |
| 연습실예약 | 예약이 쌓이는 곳 | 취소하려면 상태를 `취소`로 (행은 지우지 마세요) |
| 상담가능시간 | 요일별 방문·체험 상담 가능 시간 | 요일·시작·종료 입력 |
| 휴무일 | 상담 안 받는 날 | 날짜 입력 (2026-10-03 형식) |
| 상담 | 상담 신청이 쌓이는 곳 | 연락 후 상태 바꾸기 (연락완료 → 등록 등) |
| 로그 | 오류·알림 실패 기록 | 문제가 생겼을 때만 보기 |

> **주의** — 연습실 방이 기존 레슨실(A1~A4 등)과 같은 방이라면, 두 시스템은 서로의 예약을 모릅니다.
> 같은 방이면 레슨 시간과 연습실 예약이 겹칠 수 있으니, 연습실 탭에는 레슨에 쓰지 않는 방만 넣어주세요.

## 4. 텔레그램 알림 연결 (새 봇)

1. 텔레그램에서 **@BotFather**를 찾아 `/newbot` → 봇 이름과 아이디를 정하면 **토큰**(`123456:ABC...`)을 줍니다.
2. 새로 만든 봇과의 대화방을 열고 아무 메시지나 한 번 보냅니다. 단체방으로 받고 싶으면 봇을 그 방에 초대하고 방에서 메시지를 보내세요.
3. Apps Script **프로젝트 설정 → 스크립트 속성 → 속성 추가**:
   - `TELEGRAM_BOT_TOKEN` = 받은 토큰
4. 구글시트 메뉴 **홈페이지 → 텔레그램 채팅 ID 찾기** → 나온 숫자를
   - `TELEGRAM_CHAT_ID` = 그 숫자 (스크립트 속성에 추가)
5. **홈페이지 → 텔레그램 알림 테스트**로 메시지가 오는지 확인합니다.

토큰은 시트가 아니라 스크립트 속성에만 넣으세요. 시트를 다른 사람과 공유해도 토큰은 보이지 않습니다.

## 5. 웹 앱으로 배포

1. Apps Script 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
2. 실행 계정: **나**, 액세스 권한: **모든 사용자** → **배포**
3. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해서 Claude에게 주세요.
   저장소의 `js/config.js`에 넣으면 홈페이지 기능이 켜집니다.

코드를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**로 올려야 반영됩니다.
주소는 그대로 유지됩니다.

## 동작 규칙 (기본값, 설정 탭에서 변경)

- 연습실: 00:00~24:00, 60분 단위, 1회 최대 2시간, 한 사람 하루 최대 3시간, 오늘부터 7일 뒤까지
- 본인 확인: 수강생 탭의 이름 + 전화번호 뒤 4자리. 상태가 `휴원`·`종료`·`예시`면 예약 불가 (비어 있거나 `재원`이면 가능)
- 같은 방·같은 시간은 먼저 누른 사람만 예약됩니다 (동시에 눌러도 겹치지 않음)
- 학생 직접 취소: 시작 60분 전까지. 그 뒤는 원장님이 시트에서 `취소`로
- 상담: 상담가능시간 탭의 요일별 시간을 60분 단위로 열고, 지금부터 3시간 이후 · 14일 뒤까지만 받음
- 같은 번호로 1시간에 상담 신청은 3번까지

```bash
node --test backend/test/*.test.js   # 규칙·API 테스트 (구글 서비스를 흉내 낸 환경에서 실제 코드 실행)
node tools/dev-server.js             # http://localhost:8020 — 배포 없이 예약·상담 기능 미리보기 (체험: 김시우 / 5678)
```
