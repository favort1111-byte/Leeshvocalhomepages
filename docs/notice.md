# 학생 · 선생님 안내 문구 (2026-10-29)

홈페이지를 여는 날 카카오톡(채널 · 단톡방)에 그대로 붙여넣는 문구예요.
주소는 **leeshlesson.com** (카페24 도메인 연결이 끝난 뒤부터 열려요). 자세한 사용법 페이지는 `guide.html` (원본 `tools/guide.py`).
예약 규칙 등이 바뀌면 이 문서와 `tools/guide.py`를 같이 고쳐요.

---

## 1. 학생 공지 (카카오톡)

```
[이송희보컬레슨] 학원 홈페이지가 새로 열렸어요! 🎉
👉 leeshlesson.com

이제 홈페이지에서 이런 걸 할 수 있어요
✔ 연습실 예약 (오늘·내일, 한 번에 2시간까지)
✔ 월말평가 결과 · 평가지 보기
✔ 내방 오디션 신청 · 제휴 업체 예약
✔ 보컬 오락실 (음감 · 리듬 미니게임)

📌 처음 한 번만 해주세요
1) 첫 화면 my folder(내 폴더) → 카카오로 로그인
2) 이름 · 담당 선생님 적고 "연결 요청 보내기"
3) 원장님이 확인하면 다음부터 버튼 한 번으로 끝!

사용법 자세히 보기 👉 leeshlesson.com/guide.html
모르는 건 이 채널로 편하게 물어보세요 😊
```

## 2. 학생 공지 – 짧은 버전 (다시 알릴 때)

```
[이송희보컬레슨] 연습실 예약 · 월말평가 · 내방 오디션 신청은 이제 홈페이지에서!
👉 leeshlesson.com (처음엔 내 폴더 → 카카오로 로그인 → 이름·담당 선생님 보내기)
사용법 👉 leeshlesson.com/guide.html
```

## 3. 선생님 공지 (선생님 단톡방)

```
[선생님 안내] 레슨 일지를 이제 홈페이지에서 써요 ✍️
👉 leeshlesson.com/teacher.html

1) 카카오로 로그인 → 내 이름 고르고 "연결 요청 보내기"
2) 원장님이 승인하면 담당 학생 목록이 보여요
3) 학생 누르고 → 오늘 수업 · 준비곡 피드백 · 연습 포인트 · 오디션 일정 · 노래 추천 적고 저장
   → 지금은 학생에게 안 보여요 (원장님이 켜면 학생 "내 폴더 → 레슨 노트"에 보여요)
💡 "지난 일지 불러오기"를 누르면 지난번 내용에서 바뀐 곳만 고치면 돼요
학생이 쓴 연습 일지 · 레퍼토리도 같이 볼 수 있어요.
```
