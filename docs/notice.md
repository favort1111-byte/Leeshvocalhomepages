# 학생 · 선생님 안내 문구 (2026-10-29)

홈페이지를 여는 날 카카오톡(채널 · 단톡방)에 그대로 붙여넣는 문구예요.
주소는 **leeshlesson.com** (카페24 도메인 연결이 끝난 뒤부터 열려요). 자세한 사용법 페이지는 `guide.html` (원본 `tools/guide.py`).
예약 규칙 등이 바뀌면 이 문서와 `tools/guide.py`를 같이 고쳐요.

---

## 1. 학생 공지 (카카오톡)

```
[이송희보컬레슨] 학원 홈페이지가 새로 열렸어요! 🎉
👉 leeshlesson.com

이제 홈페이지에서 이런 걸 할 수 있어요
✔ 연습실 예약 (오늘·내일, 한 번에 2시간까지)
✔ 레슨 노트 · 연습 일지 (수업 내용 다시 보기 · 연습 기록)
✔ 월말평가 결과 · 평가지 보기 · 학원 공지
✔ 내방 오디션 신청 · 제휴 업체 예약
✔ 보컬 오락실 (음감 · 리듬 미니게임)

📌 처음 한 번만 해주세요
1) 첫 화면 my folder(내 폴더) → 카카오로 로그인
2) 이름 · 담당 선생님 적고 "연결 요청 보내기"
3) 실장님이 확인하면 다음부터 버튼 한 번으로 끝!
※ 만 14세 미만은 부모님 카카오로 로그인 → 학생 이름 적고 "부모님 카카오 계정이에요" 체크

사용법 자세히 보기 👉 leeshlesson.com/guide.html
모르는 건 이 채널로 편하게 물어보세요 😊
```

👉 leeshlesson.com (처음엔 내 폴더 → 카카오로 로그인 → 이름·담당 선생님 보내기)

## 3. 선생님 공지 (선생님 단톡방)

```
[선생님 안내] 레슨 일지를 이제 홈페이지에서 써요 ✍️
👉 leeshlesson.com/teacher.html

1) 카카오로 로그인 → 내 이름 고르고 "연결 요청 보내기"
2) 원장님이 승인하면 담당 학생 목록이 보여요
3) 학생 누르고 → 맨 위에 저번 시간 수업 내용 · 최근 연습 일지 · 레퍼토리
4) 아래 "오늘의 수업 내용"을 엑셀처럼 쓰면 2초 뒤 저절로 저장 (Tab = 다음 칸, 글자 색 · 형광펜 · 크기 OK)
   → 저장하면 학생 "내 폴더 → 레슨 노트"에 바로 보여요 (학생은 보기만)
💡 "지난 일지 불러오기"를 누르면 지난번 내용에서 바뀐 곳만 고치면 돼요
💡 아래쪽 날짜 탭을 누르면 예전 일지를 고칠 수 있어요
📷 시트 아래 "사진 올리기"로 악보 · 가사 · 자세 사진을 붙일 수 있어요 (휴대폰은 바로 찍기, 레슨 노트 사진은 학생도 봐요)
휴대폰은 주소를 열고 "홈 화면에 추가"하면 앱처럼 열려요.
```

테스트 기간용 (2026-10-30~, 학생 공지 전):
```
[선생님 안내] 학원 새 홈페이지가 열렸어요! 🎉
학생들에게는 아직 알리지 않았고, 며칠 동안 선생님들과 먼저 테스트하려고 해요.
시간 날 때 한 번씩 들어가서 둘러봐 주세요 🙏

🏠 학원 홈페이지 (학생 · 상담용)
👉 leeshlesson.com

✍️ 선생님 전용 화면 (레슨 일지)
👉 leeshlesson.com/teacher.html
1) 카카오로 로그인 → 내 이름 고르고 "연결 요청 보내기"
2) 원장님이 승인하면 담당 학생 목록이 보여요
3) 학생 누르기 → 맨 위에 저번 시간 수업 내용 · 연습 일지 · 레퍼토리
4) 아래 "오늘의 수업 내용"을 구글시트처럼 쓰면 저절로 저장돼요
   (칸 누르고 바로 쓰기 · 두 번 누르면 고치기 · Alt+Enter 줄바꿈 · 글자색/형광펜 OK)
※ 지금 쓴 일지는 학생에게 보이지 않아요. 편하게 써 보셔도 돼요.
※ 휴대폰은 주소를 열고 "홈 화면에 추가"하면 앱처럼 열려요.

불편한 점 · 이상한 점 · 바꿨으면 하는 점은 화면을 캡처해서 원장님께 보내주세요!
```

## 5. 학부모 안내 (학부모 단톡방 · 개별 문자, 2026-11-05)

> ⏸ **2026-11-10 원장님: 학부모 화면은 알리지 않기로 함 — 이 문구는 보내지 않음.** 부모님이 물어볼 때만 주소(leeshlesson.com/parent.html)를 알려 드림. 다시 알리기로 하면 이 줄을 지우고 `js/config.js parentLinks` · `tools/guide.py SHOW_PARENT`도 켜기.

```
[이송희보컬레슨] 학부모님 안내

홈페이지에서 자녀의 월말평가와 학원 일정을 확인하실 수 있습니다.

1) leeshlesson.com/parent.html 접속
2) 부모님 본인 카카오 계정으로 로그인
3) 보호자 성함 · 자녀 이름 보내기 (자녀가 여러 명이면 쉼표로)
4) 학원에서 확인하면 바로 보입니다

볼 수 있는 것: 월말평가(점수 · 단계 · 평가지) · 학원 일정 · 공지 · 학원에서 보내는 메시지
※ 보기만 가능합니다. 연습실 예약 · 신청은 학생 계정에서 합니다.
```
