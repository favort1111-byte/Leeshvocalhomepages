# 특색 메뉴 아이디어 5가지 (GPT 추천, 2026-09-26)

원장님 1차 선호: **1번, 3번**

1. **내 목소리 사용설명서** — 고민 선택(고음에 힘이 들어감 / 음정 불안 / 음색 찾기 등) + 목표·경험 질문 3~4개 →
   관련 레슨·연습 팁·수강생 사례 안내 → 고른 고민을 가지고 상담으로 연결. 진단이 아니라 관심사 안내.
2. **한 소절의 변화** — 같은 구간의 '레슨 전 → 선생님 피드백 한 가지 → 다시 부르기'를 짧게 들려줌.
   고음·음정·리듬·감정 표현별 선택. 동의받은 녹음 + 수강 기간·녹음 조건 표시.
3. **오디션 대기실** — 오디션 준비생용 준비 공간. 30초 자기소개 점검, 1·2곡 고르는 기준,
   카메라 위치·시선·반주 체크리스트, 원장님이 말하는 "준비생이 자주 놓치는 부분". 일부 공개 + 수업 연결.
4. **선생님의 귀** — 시범 영상에서 음정·호흡·리듬·표현 버튼을 누르면 선생님 해설이 나옴. 지도 방식·강사별 스타일을 보여줌.
5. **나의 첫 완곡** — "이 노래 한 곡을 끝까지"라는 목표(노래방 / 특별한 날 / 커버 영상)를 고르면
   선곡→어려운 구간→표현→녹음 과정을 보여줌. 취미 수강생용, 오디션 이미지와 균형.

## Claude 의견 요약
- 1번 + 3번 조합 추천: 1번은 취미·일반(유튜브에서 들어오는 사람), 3번은 오디션·입시생. 진입로가 자연스럽게 나뉨.
- 1번의 고민 항목을 유튜브 인기 영상(코노 212만, 고음 158만, 비음, 음치탈출)과 연결하면 새 콘텐츠 부담이 적음.
  마지막에 상담 신청 폼으로 넘기면서 고른 고민을 자동으로 채워 넣을 수 있음.
- 3번은 합격 실적과 붙어 있어야 설득력이 생김 (지금 사이트엔 합격 실적이 없음).
- 5번은 따로 만들기보다 1번의 결과 중 하나("한 곡 완곡이 목표")로 넣을 수 있음.
- 2·4번은 녹음·영상 촬영이 먼저 필요해서 나중 단계로.
- about 페이지 폴더(Audition / Hobby)에서 3번·1번으로 이어지게 하면 메뉴 버튼을 늘리지 않아도 됨.

# Claude 아이디어 (2026-09-26)

1. **바탕화면 아이콘을 진짜 파일로** — 첫 화면 아이콘(합격.jpg, 데뷔.jpg, 오디션.jpg…)을 누르면 창이 열리고 실제 내용이 나옴.
   메뉴를 늘리지 않고 내용을 담는 "형식" 아이디어. 지금 디자인 콘셉트와 가장 잘 맞음.
2. **수강생 레슨 노트** — 수업 후 선생님이 관리자 화면에 "오늘 한 것 / 다음 주 연습"을 적고, 학생이 수강 ID로 로그인해 봄.
   구 홈페이지의 매주 레슨일지를 되살림. 다니는 학생용.
3. **오디션 달력** — 내방 오디션·비공개 오디션·월말평가 일정. 관리자 화면에서 입력. 오디션 대기실과 한 페이지로.
4. **최단 3주 합격 기록** — 3주 과정을 주차별로 (이름 없이 과정만).

# 해외 사이트 조사 아이디어 (GPT, 2026-09-26)

1. **나의 인생곡 찾기** (참고: Singing Carrots) — 목적(노래방/축가/커버/오디션) + 장르·편한 노래 선택 →
   원장님이 고른 추천곡과 "이 곡으로 연습할 수 있는 것". 자동 음성 분석 없이 선생님 곡 목록으로 시작.
2. **보이스 컬러바** (참고: Complete Vocal Institute) — 같은 짧은 멜로디를 `담백하게 / 공기감 있게 / 선명하게 / 리듬감 있게`로
   부른 버전을 버튼으로 바꿔 듣고, 무엇이 달라졌는지 설명. 마음에 드는 느낌을 상담 때 이야기.
3. **오늘의 3분 보컬** (참고: Singeo, Cardon Studios) — '노래 부르기 전 / 음정 / 리듬' 중 골라 짧은 시범·따라 하기 영상. 3~5개로 시작.
4. **한 곡 해부실** (참고: Singeo) — 인기곡 한 곡의 난관 3곳(첫 소절 음정, 후렴 직전 호흡, 마지막 후렴 표현)을 구간별 설명·시범으로.
5. **LEESH Listening Room** (참고: School of Rock) — 앨범·카세트를 골라 듣는 수강생 녹음 공간. 사연 + 선생님 한 줄 코멘트, 순위·점수 없음.

GPT 의견: 보이스 컬러바가 가장 새롭고, 인생곡 찾기가 가장 실용적이며, Listening Room이 지금 디자인에 가장 잘 맞음.
