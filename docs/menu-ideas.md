# 특색 메뉴 아이디어 5가지 (GPT 추천, 2026-09-26)

원장님 1차 선호: **1번, 3번**

1. **내 목소리 사용설명서** — 고민 선택(고음에 힘이 들어감 / 음정 불안 / 음색 찾기 등) + 목표·경험 질문 3~4개 →
   관련 레슨·연습 팁·수강생 사례 안내 → 고른 고민을 가지고 상담으로 연결. 진단이 아니라 관심사 안내.
2. **한 소절의 변화** — 같은 구간의 '레슨 전 → 선생님 피드백 한 가지 → 다시 부르기'를 짧게 들려줌.
   고음·음정·리듬·감정 표현별 선택. 동의받은 녹음 + 수강 기간·녹음 조건 표시.
3. **오디션 대기실** — 오디션 준비생용 준비 공간. 30초 자기소개 점검, 1·2곡 고르는 기준,
   카메라 위치·시선·반주 체크리스트, 원장님이 말하는 "준비생이 자주 놓치는 부분". 일부 공개 + 수업 연결.
4. **선생님의 귀** — 시범 영상에서 음정·호흡·리듬·표현 버튼을 누르면 선생님 해설이 나옴. 지도 방식·강사별 스타일을 보여줌.
5. **나의 첫 완곡** — "이 노래 한 곡을 끝까지"라는 목표(노래방 / 특별한 날 / 커버 영상)를 고르면
   선곡→어려운 구간→표현→녹음 과정을 보여줌. 취미 수강생용, 오디션 이미지와 균형.

## Claude 의견 요약
- 1번 + 3번 조합 추천: 1번은 취미·일반(유튜브에서 들어오는 사람), 3번은 오디션·입시생. 진입로가 자연스럽게 나뉨.
- 1번의 고민 항목을 유튜브 인기 영상(코노 212만, 고음 158만, 비음, 음치탈출)과 연결하면 새 콘텐츠 부담이 적음.
  마지막에 상담 신청 폼으로 넘기면서 고른 고민을 자동으로 채워 넣을 수 있음.
- 3번은 합격 실적과 붙어 있어야 설득력이 생김 (지금 사이트엔 합격 실적이 없음).
- 5번은 따로 만들기보다 1번의 결과 중 하나("한 곡 완곡이 목표")로 넣을 수 있음.
- 2·4번은 녹음·영상 촬영이 먼저 필요해서 나중 단계로.
- about 페이지 폴더(Audition / Hobby)에서 3번·1번으로 이어지게 하면 메뉴 버튼을 늘리지 않아도 됨.

# 해외 사이트 조사 아이디어 (GPT, 2026-09-26)

1. **나의 인생곡 찾기** (참고: Singing Carrots) — 목적(노래방/축가/커버/오디션) + 장르·편한 노래 선택 →

# Claude 아이디어 2차 (2026-09-26, 위와 겹치지 않는 것만)

1. **심사관의 3초** — 신인개발팀 담당자가 지원 영상·사진·자기소개에서 실제로 먼저 보는 것 체크리스트. "이건 떨어지는 이유" 항목 포함.
   글만 (원장님 인터뷰 30분). 오디션 대기실 안의 한 코너로.
2. **클로이의 서랍** — 원장님이 가수 클로이로 낸 앨범 2장, 가이드 녹음(백아연·현아·펀치), OST 제작 참여를
   "서랍 속 카세트"처럼 꺼내 듣는 코너. 강사 소개를 경력표 대신 소리로. 기존 음원·영상 링크만 있으면 됨.
   원장·강사진 + Listening Room의 카세트 형식을 합친 것. 수강생 녹음 대신 원장님 음원으로 시작하면 동의 관리가 없음.
3. **월말평가 성적표** — 수강 ID로 로그인하면 이번 달 월말평가 피드백을 봄. 원장님은 관리자 화면에서 월 1회 입력.
   레슨 노트(매주)를 매월로 줄인 버전. 월말평가는 이미 하고 있어서 새로 할 일이 없음.
4. **연습실 사용설명서** — 방 6개를 하나씩 소개(피아노·컴퓨터·50cm 방음·1인 춤연습실)하고 "새벽 2시에도 열려 있어요" 같은 실제 장면.
   따로 메뉴를 만들지 않고 booking 페이지 위쪽에 사진 몇 장 + 한 문단으로. 글 + 사진.

## 비교 메모
- 겹침: 오디션 게시판 = 오디션 달력 = 학원 소식 / 3주 달력 = 최단 3주 합격 기록 / 노래방 진단 = 내 목소리 사용설명서.
- 합치기: **오디션 대기실** = 심사관의 3초 + 3주 합격 기록 + 오디션 달력 (읽는 곳 → 지금 열리는 오디션이 있는 곳).
  **내 목소리 사용설명서** 결과 화면에 인생곡 찾기·나의 첫 완곡을 넣음.
- 빼도 되는 것: 한 소절의 변화, 선생님의 귀, 보이스 컬러바, 오늘의 3분 보컬, 한 곡 해부실 (새 녹음·촬영이 계속 필요, 혼자 운영에 부담).
  Listening Room(수강생 녹음)은 나중에. 수강 후기 게시판은 어느 학원에나 있어서 특색이 안 됨.

# 해외 사이트 조사 2차 (Claude, 2026-09-26)

> 작업 환경에서 외국 사이트 직접 접속이 막혀 있어 검색에 남은 페이지 제목·요약으로 확인함. 세부 문구는 원장님이 직접 확인 필요.
> 이미 보드에 있는 것과 같아서 뺀 것: 월례 영상 평가(Keens·Avex) = 월말평가 성적표, VOAT 월례 교내 오디션 = 오디션 달력, 학생 녹음 포럼(켄 탬플린) = Listening Room.

## 운영 방식
1. **분기 1회 미니 무대 + 관객 투표** (Avex Artist Academy "Vocal Try Stage", 시어뮤직 "시어라이브", 런던 City Academy) —
   3개월마다 수강생이 한 곡씩, 가족·친구가 투표로 "베스트 액트"를 뽑음. 무대 자체가 실력 체크. 분기 1회.
2. **월 1회 원장 피드백 데이** (셰릴 포터 마스터클래스) — 한 사람당 10분씩 노래하고 원장님이 직접 피드백, 정원 제한. 날짜만 바꾸는 페이지 하나.
3. **오픈 상담 시간** (Musicians Institute "Open Counseling") — 레슨과 별도로 매주 30분 열린 상담 시간을 홈페이지에 고지. 비용 0.
4. **스카우트 내방 숫자 표기** (일본 VOAT: 연 30개사·50명) — 합격 파일에 "매월 내방 오디션, 기획사 ○○곳"처럼 숫자로.

## 페이지·콘텐츠
5. **체험레슨 1시간 흐름표** (시어뮤직, 뉴욕보컬코칭 "첫 레슨에 뭘 하나요") — 설문 → 설명 → 목소리 듣기 → 체험 → 상담, 총 1시간. "5~10분 전 도착"까지. 글만.
6. **오디션 준비 가이드 한 장** (영국 BIMM) — 대조되는 스타일 2곡, 각 1절+후렴, MR 규칙. 오디션 대기실에 바로 들어갈 내용.
7. **학부모 안내 페이지** (Keens Academy "For Parents") — 입시생 부모가 궁금한 것만 따로. 글만.
8. **음역대 자가 체크** (30 Day Singer "Find my range") — 앱 없이 안내 페이지로. 내 목소리 사용설명서의 한 코너.
9. **레벨별 종료 조건** (Berklee 개인레슨 Level 1~6, Estill 자격 사다리) — "반주에 맞춰 암보로 부르면 끝" 식으로 명문화. 커리큘럼 4 STEP에 한 줄씩.
10. **워밍업 오디오 1개 선물** (로저 러브) — 카카오 채널 추가하면 원장님 워밍업 음원 하나. 원장님 녹음 1개.
11. **오디션 영상 리뷰** (독일 트리스탄 파레데스 리액션 영상) — 수강생 동의 하에 원장님이 심사관 눈으로 짧게 코멘트. 월 1개.

## 참고
- 호주 Vox Academy가 "3주 안에 향상 보장"을 내세움. 우리는 실제 3주 합격 기록이 있어서 더 강함.
- Claude가 고른 상위 4개: 체험레슨 흐름표, 오디션 준비 가이드, 분기 미니 무대, 학부모 안내.
