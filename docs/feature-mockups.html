어디에 생기나

  • 내 폴더에 "연습 도장" 탭 하나
  • 바탕화면 내 폴더 아이콘 옆에 작게 "🔥 6"

어떻게 움직이나

  • 이미 쌓이고 있는 연습 일지 · 연습실 예약 기록으로 계산해요. 학생이 따로 할 일이 없어요.
  • 3일 · 7일 · 14일 · 30일을 채우면 폴더 테마나 스티커가 열려요. 돈이 드는 선물은 없어요.
  • 다른 학생의 기록은 서로 안 보여요. 담당 선생님과 관리자는 볼 수 있어요.

원장님이 정할 것

  • 도장 기준: 연습 일지나 연습실 중 하나만 해도 찍기 추천 / 연습 일지를 써야만 찍기
  • 하루 빠지면: 한 달에 2번까지는 봐주기 추천 / 바로 0일로
  • 30일 연속을 채운 학생을 학원에서 따로 칭찬할지 (예: 선생님 화면에 표시)

알아 둘 점: 연습실은 예약 기록으로 세기 때문에, 예약만 하고 안 온 날도 도장이 찍혀요.

시안 ②

보컬 유형 테스트

질문 20개에 답하면 네 글자 보컬 유형(16가지)과 결과 카드가 나와요. 로그인 없이 누구나 할 수 있어서, 학생이 친구에게 보내면 학원 홍보가 돼요.

어디에 생기나

  • 첫 화면 아이콘 하나 (예: test.jpg)와 보컬 오락실 안
  • 결과 화면 아래에 "내 유형에 맞는 레슨이 궁금하다면 → 카카오톡 상담"

어떻게 움직이나

  • 보컬을 4개 영역으로 나눠서 물어요: 소리(파워 P / 소프트 S) · 음악(멜로디 M / 그루브 G) · 표현(감성 E / 컨트롤 C) · 무대(라이브 L / 레코딩 R).
  • 영역마다 5문항이고, 더 많이 고른 쪽 글자가 붙어요. 5문항이라 동점이 없어요.
  • 네 글자를 모으면 유형이 돼요. 예: PMEL = 파워 디바. 모두 16가지예요.
  • 결과에는 영역마다 어느 쪽으로 얼마나 기울었는지와, 기운 쪽을 보완하는 연습 팁이 나와요.
  • 유형마다 떠오르는 한국 가수 3명이 나와요. 이름만 쓰고 사진은 쓰지 않아요.
  • 결과 카드를 그림으로 저장하거나 링크를 복사해서 인스타 스토리 · 카톡에 올릴 수 있어요.
  • 답은 저장하지 않아요. 개인정보를 받지 않아요.

원장님이 정할 것

  • 문항 20개와 16유형 이름 · 설명 · 연습 팁은 제가 쓴 초안이에요. 보컬 용어(진성 · 가성 · 호흡 · 박자 밀고 당기기)가 맞게 쓰였는지 원장님이 봐 주세요.
  • 유형별 가수 48명은 제가 고른 예시예요. 어울리지 않는 가수나 빼고 싶은 가수가 있는지 봐 주세요.
  • 4개 영역 나누는 기준이 학원에서 가르치는 방식과 맞는지. 월말평가 4항목(기본기 · 보컬 테크닉 · 액팅 · 스타일링)에 맞춰 다시 짤 수도 있어요.
  • 결과에 원포인트 레슨 영상을 유형마다 하나씩 붙일지.

재미로 하는 테스트라서 결과 화면에 "재미로 보는 테스트예요"를 작게 적어 둘게요.
