실제로는 버튼 없이, 연습 일지를 쓰거나 예약한 연습실 시간이 지나면 저절로 찍혀요.

어디에 생기나

  • 내 폴더에 "연습 도장" 탭 하나
  • 바탕화면 내 폴더 아이콘 옆에 작게 "🔥 6"

어떻게 움직이나

  • 이미 쌓이고 있는 연습 일지 · 연습실 예약 기록으로 계산해요. 학생이 따로 할 일이 없어요.
  • 3일 · 7일 · 14일 · 30일을 채우면 폴더 테마나 스티커가 열려요. 돈이 드는 선물은 없어요.
  • 다른 학생의 기록은 서로 안 보여요. 담당 선생님과 관리자는 볼 수 있어요.

원장님이 정할 것

  • 도장 기준: 연습 일지나 연습실 중 하나만 해도 찍기 추천 / 연습 일지를 써야만 찍기
  • 하루 빠지면: 한 달에 2번까지는 봐주기 추천 / 바로 0일로
  • 30일 연속을 채운 학생을 학원에서 따로 칭찬할지 (예: 선생님 화면에 표시)

알아 둘 점: 연습실은 예약 기록으로 세기 때문에, 예약만 하고 안 온 날도 도장이 찍혀요.

시안 ②

보컬 유형 테스트

질문 8개에 답하면 "나는 ○○형 보컬" 결과 카드가 나와요. 로그인 없이 누구나 할 수 있어서, 학생이 친구에게 보내면 학원 홍보가 돼요.

어디에 생기나

  • 첫 화면 아이콘 하나 (예: test.jpg)와 보컬 오락실 안
  • 결과 화면 아래에 "내 유형에 맞는 레슨이 궁금하다면 → 카카오톡 상담"

어떻게 움직이나

  • 유형은 6가지예요: 파워 디바 · 감성 발라더 · 그루브 리듬 · 무대 퍼포머 · 음색 요정 · 완벽 테크니션.
  • 결과 카드를 그림으로 저장하거나 링크를 복사해서 인스타 스토리 · 카톡에 올릴 수 있어요.
  • 답은 저장하지 않아요. 개인정보를 받지 않아요.

원장님이 정할 것

  • 유형 이름 · 설명 · 연습 팁: 지금 글은 제가 쓴 초안이에요. 원장님 말로 고쳐 주시면 훨씬 좋아져요.
  • 질문 8개도 초안이에요. 빼거나 바꿀 질문이 있는지.
  • 결과에 원포인트 레슨 영상을 유형마다 하나씩 붙일지.

재미로 하는 테스트라서 결과 화면에 "재미로 보는 테스트예요"를 작게 적어 둘게요.
