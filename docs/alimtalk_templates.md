# 카톡 자동발송 · 알림톡 템플릿 초안 (2026-11-10)

홈페이지 관리자 → **카톡 자동발송**에 넣은 일정을 전날 오후 6시에 솔라피 알림톡으로 보냅니다.
아래 5개를 솔라피 콘솔 → 카카오 알림톡 → 템플릿 등록에 그대로 붙여넣고 검수 신청해 주세요.
승인되면 템플릿 ID(KA01TP…)를 관리자 → 카톡 자동발송 → "솔라피 연결 · 템플릿 설정"에 종류별로 넣습니다.

공통
- 템플릿 유형: 기본형 · 메시지 유형: 기본형(정보성)
- 변수는 4개만, 이름 그대로: `#{이름}` `#{일시}` `#{장소}` `#{안내}`
  - 이름: 학생 이름 (상담은 신청한 분 이름)
  - 일시: "11월 15일(일) 오후 3시" 모양으로 홈페이지가 채움
  - 장소: 관리자 화면에 적은 장소, 비우면 "이송희보컬레슨"
  - 안내: 관리자 화면에 적은 안내, 비우면 "-"
- 버튼은 없어도 됩니다. 넣고 싶으면 "채널 추가" 버튼 정도만 (버튼을 넣으면 홈페이지 코드도 맞춰야 해서 미리 알려 주세요).

---

## 1. 상담

```
[이송희보컬레슨] 상담 예약 안내

안녕하세요, #{이름}님.
내일 상담 예약을 안내드립니다.

▶ 일시: #{일시}
▶ 장소: #{장소}
▶ 안내: #{안내}

일정 변경이 필요하시면 카카오톡 채널로 미리 말씀해 주세요.
감사합니다.
```
