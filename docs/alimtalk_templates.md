# 카톡 자동발송 · 알림톡 템플릿 (2026-11-11 원장님 문구)

홈페이지 관리자 → **카톡 자동발송**에 넣은 일정을 전날 오후 6시에 솔라피 알림톡으로 보냅니다.
아래 문구를 솔라피 콘솔 → 카카오 알림톡 → 템플릿 등록에 그대로 붙여넣고 검수 신청해 주세요 (관리자 화면 "알림톡 문구"의 **복사** 버튼과 같은 글).
승인되면 템플릿 ID(KA01TP…)를 관리자 → 카톡 자동발송 → "솔라피 연결 · 템플릿 설정"에 종류별로 넣습니다.

공통
- 템플릿 유형: 기본형 · 메시지 유형: 기본형(정보성)
- 바뀌는 자리 (홈페이지가 채움, 문구에 있는 자리만 보냄)
  - `#{이름}`: 학생 이름 (상담은 신청한 분 이름)
  - `#{시간}`: "오후 6시" (일정 넣을 때 고른 시간)
  - `#{일시}`: "11월 15일(일) 오후 3시" (날짜까지, 예전 문구용)
  - `#{강사}`: 일정 넣을 때 적은 강사, 비우면 학생의 담당 선생님 (담당 원장님 → 이송희). 문구에서 뒤에 "T와"(첫 레슨 · 보강) · "과"(특강)가 붙음
  - `#{클래스}`: 오디션반 · 오디션 심화반 · 입시반 · 전문반 · 취미반 중 고른 것
  - `#{특강}`: 특강 주제 (예: 헤어메이크업)
  - `#{장소}`: 적은 장소, 비우면 "이송희보컬레슨"
  - `#{안내}`: 적은 안내 · 준비물, 비우면 "-" (특강은 "따로 챙기실 준비물은 없어요!")
- 버튼은 없어도 됩니다.
- 예전 초안(기본형 · 짧은 형 · 친절한 형 · 준비 안내형)은 관리자 화면 "예시 문구 고르기"에 그대로 있습니다.

## 1. 첫 레슨

원장님 문구 그대로. 보내기 전: 첫 레슨 등록할 때 전화번호도 미리 등록해 두기.

```
[이송희보컬레슨학원 수업 리마인더]
안녕하세요 #{이름}님! 😻
내일 #{시간}, #{강사}T와 함께하는
#{클래스} 1:1 보컬레슨이 시작됩니다!
목표하시는 오디션을 향해
저희가 함께 차근차근 준비하겠습니다.
궁금한 점은 언제든 편하게 문의 주세요!
내일 뵙겠습니다 💛
이송희보컬레슨학원 드림
```
