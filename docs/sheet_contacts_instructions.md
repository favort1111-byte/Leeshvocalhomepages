> 원장님: 아래 상자 안 글을 그대로 복사해서 **학생관리 시트를 맡은 세션**에 붙여넣어 주세요.

```
[홈페이지 카톡 자동발송용 연락처 보내기 — 원장님 2026-11-10 결정]

지금 "수강ID 관리" 탭을 3시간마다 홈페이지 sheet_sync_members로 보내는 따로 만든 Apps Script(시트 읽기 전용)에,
같은 실행 안에서 아래를 하나 더 붙여 주세요. 학생관리 시트 자체는 절대 고치지 않습니다 (읽기만).

1) 읽을 곳: '회차·결제 관리' 탭, 5행부터 A열(수강ID) · P열(결제 연락처 (관리자 입력)).
   - A열이 E로 시작하는 줄만. P열이 비어 있어도 그 줄을 보냅니다(빈 칸 = 홈페이지에서 번호 지움).
   - 같은 수강ID가 여러 줄이면 P열이 채워진 마지막 줄 하나만.
2) 보낼 곳: 같은 Supabase 주소의 RPC  sheet_sync_contacts
   POST {SUPABASE_URL}/rest/v1/rpc/sheet_sync_contacts
   헤더 apikey / Authorization 은 지금 sheet_sync_members 부를 때와 똑같이
   body = { "p_key": <지금 쓰는 연결 열쇠 그대로>, "p_rows": [ { "id": "E001", "phone": "010-0000-0000" }, ... ] }
   - 번호는 시트 글자 그대로 보내면 됩니다 (홈페이지가 숫자만 골라 010xxxxxxxx로 정리, 번호가 여러 개면 첫 번호).
   - 응답: { ok, saved, cleared, skipped }. 실행 기록에는 개수만 남기고 번호는 남기지 마세요.
3) 횟수: 지금처럼 3시간마다, 바뀌었을 때만(연락처 목록의 해시가 지난번과 다를 때만) 보내도 됩니다.
4) 권한: 지금 스크립트와 같은 spreadsheets.readonly 그대로. 새 권한 · 새 트리거는 만들지 마세요.
5) 끝나면 "연락처 보내기 붙임 · 첫 실행 saved N" 만 알려 주세요 (번호는 채팅에 쓰지 마세요).
```
