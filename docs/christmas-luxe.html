HOLIDAY 2026 Merry Christmas 이송희보컬레슨

겨울밤 버전 (지금 시안)

색
밤하늘 남색 · 보라 + 네온 분홍 · 전구 노랑
글씨
G마켓 산스 굵게 (홈페이지와 같음)
움직임
불빛 트리 · 별똥별 · 불빛 쇼 · 산타 썰매 · 눈 3겹
느낌
신나고 화려함, "우와"
잘 맞는 사람
10대 학생

백화점 고급 버전 (이 화면)

색
진초록 + 샴페인 금색, 와인색 오너먼트 조금
글씨
얇은 세리프 (영어 Cormorant · 한글 명조)
움직임
천천히 흔들리는 오너먼트 · 드문 눈 · 금빛 반짝임 · 글자에 빛 지나감
느낌
차분하고 비싸 보임, 쇼윈도
잘 맞는 사람
학부모님 · 처음 오는 상담 손님

고르실 것

  • 둘 중 하나로 갈지, 섞을지 (예: 첫 화면은 고급 버전 + 내 폴더 · 오락실은 겨울밤 버전)
  • 섞는다면 고급 버전에 가져올 것: 오르골 캐럴(이미 있음) · 트리 · 산타 썰매 중
  • 세리프 글씨는 크리스마스 장식에만 씀 (평소 홈페이지 글씨는 G마켓 산스 그대로)

화면을 누르면 금빛 반짝임, 아래 "오르골 캐럴"을 누르면 겨울밤 버전과 같은 5곡이 나와요.
